# CloudGuard REST API Reference

Generated by `backend/scripts/generate_api_docs.py` from the live OpenAPI schema ([`openapi.json`](openapi.json)). Interactive docs while the backend runs: **http://127.0.0.1:8000/docs** (Swagger UI) and **/redoc**.

**Authentication.** `POST /api/auth/login` returns an access token (30 min) and a refresh token (7 days, rotated on every use; re-use of a rotated token revokes all sessions). Send `Authorization: Bearer <access_token>`. WebSockets authenticate with `?token=<access_token>`.

**Conventions.** Lists are paginated with `page` and `page_size` (max 200) and return `{items, total, page, page_size}`. Validation errors return `422` with `{detail, errors:[{field, message}]}`. `401` not authenticated · `403` role not permitted · `404` not found *or not visible to you* · `409` state conflict · `423` account locked · `429` rate limited · `503` optional integration unavailable.

**Access levels.** 🔓 public · 👤 any signed-in user · 🛡️ administrator only. Container/VM actions marked 👤 additionally require the resource to be assigned to the user (admins: all).

## Prometheus

`GET /metrics` exposes `cloudguard_host_cpu_percent`, `_memory_percent`, `_disk_percent`, `_net_send_bytes_per_second`, `_net_recv_bytes_per_second` and `_process_count` (optionally protected with `PROMETHEUS_TOKEN`).
